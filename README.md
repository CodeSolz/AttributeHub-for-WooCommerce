<h2 align="center">AttributeHub for WooCommerce - WordPress Plugin</h2>

### Description

**AttributeHub for WooCommerce** is a master attribute mapping plugin that creates a safe display layer between your messy backend attribute values and clean, customer-friendly filters — without touching your original product data.

Many WooCommerce stores import products from suppliers, ERPs, CSV files, or dropshipping sources. The backend product data often contains supplier abbreviations, color codes, and internal values that look terrible in customer-facing filters. AttributeHub solves this by letting you map many raw backend values to one clean master label — so your customers see "Black" while your backend still holds BK, BLK, BCK, and MULTIBK.

Your original attribute data is never modified, keeping inventory systems, ERP integrations, and future imports completely safe.

### Key Features ###

* **Attribute Scanner** – Automatically detects abbreviated, ugly, and duplicate attribute values across all your WooCommerce attributes.
* **Master Attribute Directory** – Create clean master labels and map multiple backend values to a single display label.
* **Mapping Editor** – Drag-and-drop interface for assigning raw attribute values to master groups.
* **Clean Frontend Filters** – Your layered navigation shows master labels instead of raw supplier codes, with no theme or plugin changes needed.
* **Smart Filter Query Expansion** – Filtering by "Black" automatically returns ALL products mapped to Black, regardless of which raw code they use.
* **Preview Mode** – Compare before/after filter appearance before going live, with zero risk.
* **Product Metabox** – Shows the mapping status of each attribute directly on the WooCommerce product edit screen.
* **Hide Unmapped Values** – Optionally suppress unmapped or ugly values from frontend filters until they are mapped.
* **Duplicate Detection** – Groups near-identical attribute values for efficient batch mapping.
* **CSV Export** – Export your mapping configuration for backup or staging-to-production workflows.
* **WooCommerce HPOS Compatible** – Fully works with High Performance Order Storage.
* **Role-Based Access** – Restrict AttributeHub management to specific WordPress user roles.

### How to Get Started ###

* **Step 1 – Install & Activate**: Upload the plugin and activate it from the WordPress Plugins menu.
* **Step 2 – Scan your attributes**: Go to **AttributeHub → Scanner** and click **Scan Now** to detect all existing attribute values across your products.
* **Step 3 – Create master labels**: In **AttributeHub → Master Labels**, create clean display names (e.g., "Black", "Gold", "Silver").
* **Step 4 – Map your values**: In **AttributeHub → Map Values**, drag raw backend values (BK, BLK, BCK…) onto their master label.
* **Step 5 – Preview**: Use **Preview Mode** to verify your filters look correct before enabling for shoppers.
* **✅ Important Tip:** Your original attribute data is never changed. You can remap or disable at any time without affecting your backend data.

## Pro Features ##

### Mapping & Filtering Features: ###
    * Secondary Color Tags — a product appears in multiple master label filters simultaneously (e.g., a gold earring with black stones shows in both Gold and Black)
    * Advanced Rules Engine — pattern-based auto-mapping: "starts with BK → Black", wildcard and regex rules
    * Auto-Map New Imports — automatically maps newly imported product attributes based on your saved rules
    * Bulk Editor — spreadsheet-like interface for managing hundreds of mappings at once
    * CSV Import — import mapping configurations from CSV (ideal for agencies and staging-to-production workflows)

### Analytics & Automation Features: ###
    * Filter Analytics — track which filters customers click and which drive the most conversions
    * Scheduled Scans — automatically detect new unmapped values from nightly product imports
    * Email Reports — receive notifications when new unmapped attribute values appear in your store

### AI & Integrations: ###
    * AI Label Suggestions — AI suggests clean display names for messy supplier codes (98% accuracy on abbreviations)
    * FacetWP, YITH, Elementor Compatibility — bridges for popular third-party filter plugins
